# Tech Stack

## Frontend

| Параметр           | Значення                    |
|--------------------|-----------------------------|
| Фреймворк          | React                       |
| Стан застосунку    | Zustand                     |
| Маршрутизація      | React Router                |
| Стилізація         | CSS variables + CSS Modules |
| Збірка             | Vite                        |

Чому обрали: Router - публічні/приватні маршрути; Zustand - простий стейт; CSS variables - як у ТЗ; Vite - швидка збірка.

## Backend

| Параметр           | Значення     |
|--------------------|--------------|
| Мова               | Rust         |
| Фреймворк          | Axum         |
| База даних         | PostgreSQL   |
| ORM / драйвер      | SQLx         |
| Автентифікація     | jsonwebtoken |
| Документація API   | OpenAPI      |

Чому обрали: Rust обрали через високу продуктивність, безпечну роботу з пам’яттю та найнадійнішу системі типізації, що допомагає виявляти майже всі помилки ще на етапі компіляції. Технологічний стек Axum + Tokio + SQLx + PostgreSQL забезпечує ефективну асинхронну обробку запитів, надійну роботу з базою даних і зручну побудову REST API.
